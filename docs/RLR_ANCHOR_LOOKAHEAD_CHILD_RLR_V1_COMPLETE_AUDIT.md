## Tested hypothesis and model form

An ordinal anchor root `sum_{a in A}1[x_g>x_a]>=t` partitions the patients so *different supervised RLR gene-pair coefficients* can improve the two child submodels. All prediction inputs are **within-patient rank/ordinal comparisons**. A new patient needs the same exact probe/gene universe but not training-sample abundance ranges.

Global original RLR K20 remains a fixed binomial-logit offset. At each of the two terminal branches, local supervised switchBox pair selection is trained strictly on that branch's D examples, d1/K8/m10, and a penalized elastic-net conditional correction (alpha=.5, fixed lambda=.10, intercept=FALSE) is fit using original RLR logit offset. If untrainable, the local expert returns global original RLR probabilities. A rooted structure with two distinct branch-specific RLR predictors is a **true one-root model tree** (not a recursively learned depth-two decision tree), with existing model-tree prior art.

D-specific parent RLR OOF residuals from three internal folds cheaply score at most 12 TSP gene hubs × reference panels 3/5 × discrete thresholds for their predicted conditional improvement vs common coefficient, using at most 160 original D rank-pair columns; retain up to 6 root proposals. Unlike the greedy alternative, the look-ahead ranking attempts to predict child RLR ability. Importantly, the anchor *panels themselves* are still generated by the earlier globally oriented TSP-neighbor/rank-stability heuristic. **This V1 is a look-ahead re-ranking of root panels, not yet an actual optimization of each anchor gene by downstream child RLR quality.** This distinction is important for a future method.

An inner D/V training-only gate requires V logloss >=.008 improvement vs D original RLR, >=.004 improvement vs same-pair global model, >=.004 vs gate-only and V BA loss <=.02, else exact full-T original RLR fallback.

## Full comparator design and fairness correction

An early six-arm exploratory run unfairly reselected **greedy comparator branch pair identities on all T**, while look-ahead branch pair IDs were D-only. Before final run, **both** methods were changed to freeze supervised child pair identities on the same inner D, refitting only coefficients on T. No hyperparameter or E-guided tree search changed. Added two necessary non-tree greedy controls to investigate whether the observed greedy-root signal was actually branch-specific. Both changes were explicitly recorded in the protocol appendix.

Eight E-aligned arms:
1. Original K20 RLR.
2. Greedy D root + D-selected child pair RLR, T coefficient refit.
3. Same greedy child pair union and root gate in one global nonbranch elastic-net (no branch-specific coefficients).
4. Same greedy root gate only (no child pairs).
5. OOF-lookahead-selected root + two child RLR experts.
6. Same look-ahead child pair union and root gate in one global model.
7. Look-ahead root gate only.
8. V-gated look-ahead root+child-RLR (or exact original RLR).

## Correct, independently verified actual run

Cohorts: **reused**, previously explored Chowdary-2006 104 samples/182 filtered genes and Singh-2002 102/339; public Schliep-source reconstructions, not SHA-proven identical to original processed paper ARFF. 3 outer stratified E folds per cohort, seed42, 6 total. 8 model arms × 6 = **48 model-fold scores**, 206 patients × 8 = **1648 archived heldout model-patient probabilities**. Independent Python audited every individual E patient ID, class identity, probability and original RLR fallback and reproduced **Macro-F1, BA, Brier, logloss and delta logloss** across all model-folds: PASS. Mechanical R tests proved rank invariance for independent within-patient monotone transformations, gate-only and same-pairs-global models, trained local RLR predictors, D residual root candidate ranking, strict probe universe: PASS.

This is **not independent clinical or biomedical validation** and has zero evidence of novelty/superiority against the original CUDA TSPDT (never executed here).

The greedy model has NOT been shown better BA than original RLR.

## Research decision

- **Freeze V1 look-ahead: not superior to greedy and no accepted E benefit.** Do not run posthoc lambda/candidate/support threshold searches against these six E outcomes.
- The user proposed optimization of anchors by **child model quality**, not merely choosing the root from globally TSP-selected anchors. V1 only approximates that target by re-ranking existing star panels; direct D-only anchor swap/beam search remains a scientifically distinct, possible next project, but should first show reproducible feasibility gains on train-only data and then be tested on genuinely fresh cohorts.
- A more immediate and defensible advance is to study the **greedy-root RLR model-tree** as a distinct method, including training-only validation acceptance, patient-path active pair counts, stability of root/reference selection across repeated D splits and a fair original TSPDT CUDA benchmark.
- Do not equate a one-root RLR model tree with a depth-two top-down decision tree. No EA has yet been performed in this phase; EA could search anchor panels but would require an independent inner validation protocol.
- The original completed RLR manuscript and source remain intact and ready for submission if no tree extension survives independent evaluation.
