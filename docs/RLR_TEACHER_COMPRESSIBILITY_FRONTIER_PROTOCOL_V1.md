# RLR teacher compressibility frontier: fixed diagnostic protocol

**Research phase 2026-10-29.** No new predictive architecture or claimed novelty. Previous v1–v5 tree variants negative or inconclusive. Diagnostic addresses whether the **strictly bounded depth-2 rank-tree representation** can fit an RLR20 output *even with exact global optimization over a fixed panel*. This is an optimistic training-capacity diagnostic only, NOT a universal capacity theorem nor prospective generalization.

**Data and leakage rule:** first original outer T in each of 11 original paper-named public Schliep reconstructions; split T into fixed D/V. Outer E never read in the diagnostic. Actual ARFF source identity unverified; all 11 cohorts have been repeatedly inspected. Source selection only from D. Teacher targets: **threefold true D-only OOF RLR20** (Pomeroy rare-class ridge surrogate folds explicitly flagged); comparison parent: frozen full-D original RLR20 evaluated on V only for heldout fidelity. Model inference never runs RLR.

**Fixed experiment (no tuning):** 2 optimization targets × four node budgets (0,1,2,3) = 8 diagnostic arms per cohort, plus one RLR reference. Same D-only switchBox TSP-top20 candidate pairs, same minleaf=max(4,floor(.07*nD)), same maximum depth 2, same rank invariance and identical patient splits.
- TEACHER: globally minimize within-leaf sum squared deviations of D-OOF RLR20 **logits**. Exactly search every valid root and best optional second level left/right; capped at k internal nodes, allowing fewer if no beneficial splits.
- LABEL: globally minimize true-label training cross-entropy with smoothed probabilities under identical tree capacity and pool.
- For **every induced topology**, compute both (a) smoothed probabilities from true D labels, and (b) D-OOF teacher projected probabilities from logit means in leaf. **The same OOF teacher projection is fitted on label-only trees as well** so tree structure can be compared without leaf-estimator confounding. On V use (a) for label-quality F1/AUC/logloss, (b) for fidelity to frozen full-D RLR20. These are distinct diagnostic outputs and not a chosen new classifier.
- Training loss ratio at capacity k vs capacity zero is an **in-pool optimistic empirical fit ceiling**, not an upper bound on unknown samples or richer models; zero denominator explicitly marked. Honest heldout V exposes generalization mismatch. Cap 0 exact constant benchmark; cap 3 still max 2 evaluated rank-pair tests/patient (full expression feature universe required to calculate ranks).

**Verification:** independent brute-force unit test, per-patient V prediction replay, D/V disjoint, no outer E, positivity map, path comparisons <=2, exact 88 cohort-model records plus 11 reference methods, monotone training loss at increasing capacities, teacher fidelity Brier and teacher-label agreement, label F1/AUC/logloss/Brier, train loss fraction, genes and pair counts. Exact signflip at 11-cohort unit level; no fold/patient pseudoreplication.

**Decision:** if even best teacher-target train fit cannot explain RLR with <=2 path comparisons using TSP-top20 tests, evidence of constrained *in-sample representation*, not proof of impossibility. If fit training but not heldout V, overfitting/stability issue. Do not launch v6 or 470 folds from this alone. Compare eventually with authentic historical CUDA TSPDT and original processed ARFF; neither is currently present as runnable original source in GitHub. No manuscript edits. No automation.
