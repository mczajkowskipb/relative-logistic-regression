# QRLR V1 — pair-specific ordinal rank uncertainty band (exploratory development protocol)

**Research motivation:** original RLR m=10 defines a ternary signed rank feature `r_ij=+1` if `rank(j)-rank(i)>=10`, `r_ij=-1` if ≤−10, and 0 otherwise. In the audited original 11-cohort full470 benchmark, original RLR20 retains mean 16.63 globally nonzero beta coefficients, but 15.10 ternary pair states remain nonzero per patient (only ~9% locally inactive), so simply claiming nominal vs active sparsity is not the strongest novelty. Meanwhile using a global orientation-dependent unweighted SAVS rule causes substantial F1 loss. The previous supervised margin-aware *pair reordering* also did not produce a consistent F1/AUC gain on completed 470 E folds.

**New testable hypothesis:** the *rank separation required for a reliable pair vote* may differ strongly by pair. For each pair, use the TRAINING-ONLY **class-blind** rank-distance quantile `m_j = max(10, Q_q^T(|rank_s(j)-rank_s(i)|))`, with q chosen as one of the predeclared fixed values `{0,.25,.5}`. No class label is used to learn this threshold. The strict within-patient transform-invariant class-logistic feature is `r_ij(s)=sign(rank_s(j)-rank_s(i)) 1(|rank_s(j)-rank_s(i)|>=m_j)` (outcome -1/0/+1). For q=0 exact original feature m=10 and exact original probability predictions are REQUIRED as a mechanical parity test. Nonzero logistic weights still global; the ternary rank state can be zero specifically in a patient's sample.

**Historical priors:** original kTSP already uses rank differences as a secondary score (Tan et al., Bioinformatics 2005, https://pmc.ncbi.nlm.nih.gov/articles/PMC1987374/); generalized TSP/REO gene-pair ranks are established (https://pmc.ncbi.nlm.nih.gov/articles/PMC11982013/). This is **NOT** an invented new concept of patient rank differences; potential distinct element is class-blind, pair-specific *abstention bands* within original interpretable sparse logistic gene-pair model. It is presently **not a learned tree**, nor clinically validated or known to beat kTSP.

**Frozen inner-D/V trial:** original 11 previously studied paper-named CompCancer public Schliep reconstructions; exact processed original ARFF parity NOT VERIFIED. First original outer T seed42 only; split T into D/V with `rg_inner(yt)`. Both switchBox supervised original top1000 shortlist, original `apply_disjointness(d=2,K=10/20)`, *per-pair quantile thresholds*, original glmnet alpha=.5, lambda.min selected **exclusively D**. Evaluate V F1, MacroF1, BA, AUC, LL, Brier, model global coefficient count, mean active ternary relations in D and V, and actual number needing to be evaluated. All thresholds and pair IDs archived. No E patient or labels touched. 2 Ks × 3 q=6 arms ×11=66 outcomes, plus independent Python patient metric audit. q0 predicted probabilities must be identical to literal original `rg_parent`. Real [GitHub CI #40594140376](https://github.com/mczajkowskipb/relative-logistic-regression/actions/runs/40594140376).

**Scientific decision:** If q25 improves or at least retains F1 in the majority of datasets while measurably reducing active witnesses, could become a useful **interpretability-vs-performance** ablation in one unpublished original RLR article. If q50 systematically reduces F1 despite sparse votes, freeze negative; do not subsequently tune q on repeatedly exposed E. All previously explored cohorts are development data, not new external validation. Original unpublished RLR manuscript and algorithm lock untouched.
