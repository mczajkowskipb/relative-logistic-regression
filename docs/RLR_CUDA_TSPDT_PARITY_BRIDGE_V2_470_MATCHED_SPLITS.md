V1 Python exporter used pretty-printed `json.dumps(cfg,indent=2)`, which inserts a whitespace after the colon. Real parser either misreads quoted paths or fails in `stoi` for string-valued gene-block threshold.

**Reproduced on the exact original privately supplied C++ header (not an imitation)** by compiling a read-only standalone `settings` harness with `g++ -std=c++17`:

- Pretty-printed JSON: **FAIL** `EXCEPTION:stoi`.
- Compact JSON `json.dumps(cfg,separators=(',',':'))`: **PASS**, two correct existing absolute TRAIN/TEST paths, original `foldsCV=-1`, `normalization=0`, `runs=1`, and the correct `multiomicsthresholds` gene count.
- Additional probe using **actual synthetic TRAIN/TEST files generated by repaired adapter v2** and original header: `ORIGINAL_CPP_JSON_TWO_FILES_AND_OMIC_THRESHOLD=PASS`.

This is a **config format repair only**, not any change to tree induction or the original source code. Earlier reports stating the adapter was fully ready with pretty JSON must be superseded by v2.

## Remaining actual CUDA/paper reproducibility blockers

1. Private original CUDA code `cudatsp4(1).zip` must only be used on a researcher-approved NVIDIA GPU host. No `nvcc` nor NVIDIA GPU exists in the ChatGPT execution environment; no actual CUDA classification or performance has been measured. The v2 runner checks `nvcc`, `nvidia-smi`, exact config/data file SHA and per-patient predictions before it can emit `TSPDT_REAL_GPU_PATIENT_PREDICTION_AUDIT=PASS`.
2. Original processed `data/CompCancer/<cohort>.arff` bytes are absent from public GitHub (ignored by `.gitignore`); compare to the frozen expected SHA in `checksums/DATA_SHA256_EXPECTED.txt`, along with an exact `row_index,sample_id` map.
3. Pairwise comparison must use **the same source as both algorithms**. Archived RLR K50 probabilities here are SOURCE RECONSTRUCTION. Original processed ARFF CUDA data must NOT be compared to them (v2 aggregator explicitly refuses provenance mismatch). To claim original-paper parity, refit RLR on SHA-verified original ARFF with the same folds; otherwise do an *exploratory* reconstructed-source run on both algorithms, labelled such.
4. Original published CUDA TSPDT hyperparameters and the toolchain/architecture compatibility have not been independently matched, and real original TSPDT BA or Macro-F1 are unknown. The historical greedy TSPDT proxy is not the original implementation.
5. Only after 11-dataset, same-patient genuine GPU vs original RLR/K-TSP performance evidence should the unpublished RLR tree extension be judged for habilitation. Previous attempted ARLET, C-RET hierarchical policy and global K50 branch corrections produced mixed or negative tree-specific results, and must not be presented as an established novel improved classifier.

**Decision:** v2 fixes a reproducible real original source parser blocker and makes the 470-fold matched source-only benchmark technically reproducible. Actual GPU and original processed ARFF parity gates remain OPEN. Preserve user CUDA source privacy and original unpublished manuscript.
